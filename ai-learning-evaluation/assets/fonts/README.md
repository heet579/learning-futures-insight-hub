# Report fonts

Used to lay out and embed the two-page report so the PDF and the Word document measure the same.

- **Carlito** (Regular, Bold, Italic): metric-compatible with Calibri. SIL Open Font License 1.1, by tyPoland Łukasz Dziedzic.
- **Caladea** (Bold): metric-compatible with Cambria. Apache License 2.0, by Carlo de Fabritiis / Huerta Tipográfica.

The Word document asks for Calibri and Cambria; Word on Windows and macOS has both, and
LibreOffice substitutes these metric-compatible fonts, so line breaks match the PDF.
