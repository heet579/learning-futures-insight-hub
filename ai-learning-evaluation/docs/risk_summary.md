# Risk summary

| Risk | Impact | Control / response |
|---|---|---|
| Real data unavailable | Validation gap | Synthetic fixtures now; request approved anonymised exports |
| PII leakage | High privacy harm | minimise, local masking, scan output, approved-system review |
| Unsupported claims | Trust/decision harm | grounded context, evidence display, deterministic tests, human approval |
| Cultural/indirect language misread | Misrepresentation | no sentiment ground truth; source review and uncertainty |
| Minority views suppressed | Missed concern | inspect dissenting comments and low-frequency risks |
| Copilot/licensing unavailable | Integration delay | provider abstraction and local credential-free MVP |
| Invalid trend comparison | Misleading conclusion | block claims until schema/cohort comparability confirmed |
| Live demo failure | Presentation disruption | bundled data, sample reports and recovery script |
| Scope overload | Delivery failure | must-have-first rapid MVP and controlled backlog |
