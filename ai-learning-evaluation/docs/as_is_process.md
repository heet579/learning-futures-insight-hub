# AS-IS Process

```mermaid
flowchart LR
  A[Course delivered] --> B[Qualtrics survey distributed]
  B --> C[Responses collected]
  C --> D[Staff manually review]
  D --> E[Staff identify trends]
  E --> F[Staff write summary]
  F --> G[Staff develop recommendations]
  G --> H[Report prepared]
  H --> I[Stakeholder receives report]
```

Pain points include staff time, repetitive manual workload, variable structure/emphasis between reports, and difficulty scaling qualitative review. Ratings and comments must be combined into a coherent narrative for different audiences.
