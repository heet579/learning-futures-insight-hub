BRAND LOGO
----------
adelaide-university.png is the logo shown in the top bar and on the sign-in
screen, with "Learning Futures" linked below it to:
https://adelaide.edu.au/study/short-courses/for-organisations/learning-futures/

To change it, replace adelaide-university.png (keep the same name), or use a
different file and update the src in web/app.js -> brandLockup().
The logo sits on a white rounded chip, so a transparent-background PNG/SVG is best.

(uofa-logo.svg is an unused earlier placeholder; it can be deleted.)
