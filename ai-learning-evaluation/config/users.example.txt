# This repository intentionally does not contain an active users.txt file.
# From the application folder, create two local demo accounts interactively:
#   python -m src.auth init demo-author demo-reviewer
#
# Active entries are generated in this form (placeholders below are not usable):
# demo-author<TAB>pbkdf2_sha256$600000$<random-salt>$<password-digest>
# demo-reviewer<TAB>pbkdf2_sha256$600000$<random-salt>$<password-digest>
#
# Passwords are prompted without echo and are never stored as readable text.
# Blank lines and lines starting with # are ignored. Comment out or remove an
# active line to disable that local account. Never commit config/users.txt.
