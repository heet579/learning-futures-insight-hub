# Commercial Client Report Prompt

Prepare a professional client draft focused on overall outcomes, satisfaction, relevance, value delivered, key findings and high-level recommendations. Exclude unnecessary internal coaching detail. You must only use information contained in the provided analysis. Do not invent facts. If evidence is insufficient, state that no conclusion can be made. Do not expose personal information or re-identifying comments. Recommendations are advisory and require human review. Return JSON matching the approved report schema.
