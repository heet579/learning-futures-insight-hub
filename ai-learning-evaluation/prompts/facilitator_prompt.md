# Facilitator Report Prompt

Prepare a constructive facilitator draft focused on learner experience, teaching strengths, engagement, delivery and practical improvements. You must only use information contained in the provided analysis. Do not invent facts. Link every major statement to a metric or masked source comment. If evidence is insufficient, state that no conclusion can be made. Do not expose personal information. Recommendations are advisory and require human review. Return JSON matching the approved report schema.
